# Lucky Break · 海岸城三维地图

基于提供的 `city map.htm` 重构，保留程序化城市的造型、配色、地标和动画。使用 Three.js 0.160、TypeScript、Vite；Three.js 随应用打包，线上无需依赖 unpkg。

在线地址：https://GioGyan90.github.io/CityMap/

## 使用

- 鼠标左键拖拽旋转、滚轮缩放、右键拖拽平移。
- 手机单指旋转、双指缩放和平移。
- 右侧切换全景、俯视及各地标视角，开关地名或暂停场景动画。

## 本地开发

需要 Node.js 22.12+。

```sh
npm ci
npm run dev
npm run build
npm run preview
```

`npm run build` 先运行 TypeScript 检查，再生成 `dist/`。

## 代码位置

| 模块 | 用途 |
| --- | --- |
| `src/main.ts` | 启动与加载失败提示 |
| `src/scene.ts` | 渲染器、相机、控制器、灯光、天空 |
| `src/config.ts`, `random.ts`, `materials.ts` | 地图常量、确定性随机、卡通材质 |
| `src/environment.ts`, `mountains.ts`, `clouds.ts` | 岛屿、海面、山脉、云 |
| `src/buildings.ts`, `districts.ts`, `roads.ts` | 通用楼体、住宅街区、道路 |
| `src/amusement.ts`, `landmarks.ts`, `port.ts` | 游乐园、公共建筑、港口 |
| `src/vegetation.ts`, `traffic.ts` | 实例化植被与车辆 |
| `src/city.ts` | 城市布局与组装顺序 |
| `src/labels.ts`, `camera.ts`, `animation.ts` | 地名、视角与动画 |
| `src/styles.css` | 桌面与移动端界面 |

后续添加细节时，在对应地标模块添加造型，在 `city.ts` 调整位置，在 `labels.ts` 添加标注，在 `camera.ts` 添加观察视角。世界 Y 轴向上、XZ 为地面；地面高度见 `GROUND_Y`。几何体与贴图均由代码生成，没有外部模型资源。

## GitHub Pages

推送 main 自动通过 `.github/workflows/deploy.yml` 安装锁定依赖、检查并构建，然后部署 GitHub Pages。若首次自动启用被 GitHub 权限限制，在仓库 Settings → Pages → Build and deployment 将 Source 设置为 **GitHub Actions**，再重新运行工作流。

## 当前范围

本版本是地图查看器，尚未接入角色移动、任务、场景入口或地图编辑器。运行需要支持 WebGL 的浏览器。

## 城市扩展版

- 道路覆盖 8 × 11 个街区单元，住宅沿山脚继续延伸；生成多种程序化建筑。
- 十种楼型：平顶楼、坡顶楼、玻璃写字楼、退台塔楼、装饰艺术塔楼、圆形塔楼、拱廊商铺、阳台公寓、别墅和仓库。
- 高楼集中在后方金融区，滨海区域保持低层街景，东侧增加学院、运动场和花园广场。
- 新增“城市天际线”和“山麓住宅”视角。
- 摩天轮绕局部 Z 轴转动，吊舱反向补偿以保持直立；支架固定，旋转木马独立绕 Y 轴运动。
- 静态建筑按材质合并，保留车辆、游乐设施、船只的独立动画。新增或修改建筑后应在全部建造完毕时调用 `batchBuildings()`。

仓库仍使用“Deploy from a branch”时，GitHub 自带的分支发布可能晚于 Vite 发布并覆盖页面。工作流在最终部署前等待同一提交的分支发布结束，再发布编译产物，确保最终页面可运行。推荐在 Settings → Pages 中把 Source 改为 GitHub Actions，这样每次更新只需一次构建。

## 区域概念与地标聚焦

- 按区域概念加强蓝白海滨酒店、遮棚台球用品市场、蓝金商业楼、医院、海鲜餐厅、咖啡馆及邮轮，加入 1–5 号球馆标识。
- 鼠标悬停特殊建筑区域或地名，保持所选区域的彩色与高度；其余建筑平滑降到原高的 88%，使用不含贴图的灰模材质。移开后恢复原材质和高度。
- 点击地名可固定聚焦，再次点击取消；手机可轻点地标/地名。按 Esc、点击空地或开始拖动可清除固定选择。
- `specialBuildings.ts` 注册独立地标根节点和稳定拾取范围；`focus.ts` 管理拾取、过渡及材质还原；`conceptDetails.ts` 负责招牌、遮棚与区域细节；`cruiseShip.ts` 使用船体局部坐标构建邮轮。
- 特殊建筑保持独立分组，普通建筑继续按材质合批；新增地标用 `registerSpecial()` 包裹建造过程，确保描边和附属设施跟随同一聚焦状态。

## 昼夜、海面与温和聚焦

- 其他建筑只降低 12% 高度，灰模保持 80% 不透明度；选择轮廓为选中设施整体剪影的金色外描边，不绘制窗框、屋顶接缝等结构线。
- 右侧“夜间模式”切换冷蓝环境、暖色窗灯、路灯、游乐设施灯光与星月背景；本机会记住上次选择。
- `water.ts` 用动态波面法线、掠射角反光、日/月光高光和近岸泡沫替代重复浪花贴图；暂停动画同样暂停海面。
- 主干道与支路分级、部分外侧道路改为 T 形路口；中部使用较大的庭院公寓街块，滨海为低层商铺，山麓为稀疏住宅，海滨新增弯曲步道。
- `night.ts` 以实例化灯具和少量局部光源实现夜间氛围，未增加额外外部资源。

## 半岛布局与立体交通

- `layout.ts` 统一管理东西海岸轮廓、设施用地、地形高度、道路和交通预留走廊。空间关系按二维概念图调整为西侧沙滩、后方山脉与高楼、中央政府广场、东侧医院学院、南部海角酒店和东南港湾邮轮。
- `environment.ts` 生成随海岸收束的不规则高程网格与海岸岩壁，港区设填海平台及渐变接坡；大型设施采用平整用地，周围道路与植被采样同一地形高度。
- `parcels.ts` 按区域挑选建筑体量，避让大型设施、道路、铁路与高架公路；建筑地基补足坡地高差，并增加空中连廊、双体塔楼变化与屋顶玻璃空间。
- `transport.ts` 提供运行中的海滨电车、高架列车、站台、路侧候车亭、广告牌和高架公路。普通道路上的轿车、公交与高架公路车辆使用各自的路线及高度。
- `siteDetails.ts` 为大型设施补充独立庭院、绿化、摊亭和座椅。设施根节点、拾取范围、地名与相机视角随新布局同步调整。

## 组合平面、整体描边与交通防碰撞

- `buildingPlans.ts` 定义 E、T、H、L、U 型连通平面；墙面与屋面从同一凹多边形生成，庭院凹口保持开放。`parcels.ts` 为组合楼型分配更大用地，同时避让道路及相邻建筑。
- `focus.ts` 将选中设施所有网格合成同一个屏幕遮罩，只在剪影外侧绘制金色轮廓，不再为每个部件生成线框；移动设施和相机转动时同步更新。
- `trafficSimulation.ts` 使用分向车道、端部连续掉头、米制速度、车距限制、路口独占通行与车辆包围矩形检测；桥梁按高度分离。T 型接入点也纳入路口管理。
- `npm test` 检查凹多边形屋面面积与法线、五分钟完整路网车辆间距与通行情况、快慢车跟随和掉头；发布工作流先测试再构建。

## 楼翼体量与无文字市场

- 组合楼型不再整片等高拉伸：`createMassing()` 为主楼、侧翼与低层连接楼分别生成宽度、长度和高度，再由 `massingGeometry()` 合并成连续外表面，保留退台、开口和露台。尺寸由地块坐标稳定生成，不使用文字网格。
- 台球用品市场移除建筑上的文字招牌；`marketEmblem.ts` 使用台球、交叉球杆和金属支撑架作为屋顶标识。市场由高层球杆工坊、较低的拱顶展销厅、条纹摊亭和无文字的 2 号球馆组成。地图地名仍可用于定位与聚焦。
- 几何测试检查楼翼连通、屋面面积、屋面朝向、用地边界及连接处没有隐藏墙面。

## 晴日海岸配色

- `visualStyle.ts` 集中定义暖阳、蓝色补光、沙滩与海水配色；昼夜切换引用同一套白天设置，保证还原一致。
- 建筑外框由大面积深色边框改为细暖石色收边，窗框与普通几何线条改为较轻的蓝灰色；增加蓝色窗面的比例，避免去掉黑框后墙面显得单调。
- 草地与树冠增加黄绿层次，沙滩改为暖金色并沿西岸生成轻缓沙坡，海滨餐厅保留临水开口；近岸水色与新沙滩边缘同步，远海保持蓝色。
- 云层放在远山之后，暖色主光与冷色补光形成明亮墙面、清楚投影和蓝色暗部。

## 建筑入口、停车场与道路地形衔接

- `buildingAccess.ts` 从实际楼翼外墙挑选入口，生成门框、玻璃或木门、把手、踏步和雨棚；普通建筑朝向附近街道，政府大厅及医院另设主入口。
- `parking.ts` 为办公建筑寻找不侵占现有道路、建筑、设施和铁路的用地；停车场包含车位线、止轮块、停车车辆、接入车道与步行入口。停放车辆按地面坡度调整姿态；植被避让接入车道与步行路径，工具栏提供“办公停车场”近景。
- `roadNetwork.ts` 在道路两侧生成连续的整坡带；`terrainSurface.ts` 让车辆、地基、树木、路灯采样实际渲染的三角面高度。
- `groundRoadMaterial.ts` 将地面道路、人行道、标线和停车场整合到地形的同一材质上，不再叠放独立路面与草地网格，消除坡地穿插和路口重叠面的深度闪烁。高架、铁路仍保留独立结构。
- `npm test` 新增地面三角面高度采样和组合楼入口外墙定位检查，继续保留交通防碰撞回归。

## 资产查看与网格规划

地图左上角“资产查看 / 网格规划”打开编辑面板。也可以直接访问 `?view=assets`，或 `?view=assets&asset=vehicle-sedan` 查看车辆。

- 单独查看地标、车辆、普通建筑样式、船只和树木；提供正面、侧面、背面、顶部、斜视、线框、旋转、尺寸及三角面数。
- 网格单元为 20 × 20 世界单位，原点为 X=-260、Z=-220。列从 A 延伸到 AD，行从 01 到 23；例如 `A01`。Y 为竖直高度，X/Z 为平面位置。
- 在地图模式打开网格后，点击地面选取坐标，可以添加和删除位置备注。
- 地标 X/Y/Z 可作为位置草稿调整，自动保存到当前浏览器。草稿只移动地标及其标签、拾取框，不会重建配套道路和地形。
- 导出 `citymap-layout.json` 包含地标 ID、位置、网格编号、备注及道路控制点。导入会校验数据，并恢复地标位置和备注。“恢复原始位置”移除本机位置草稿，保留备注。
- 确定布局后，将 X/Z 回填到 `src/layout.ts` 的 `ZONES`；需要指定基准高度时使用 `level`，同时调整相关道路、地形和入口。不要把临时浏览器草稿当作已发布的全局布局。

车辆造型由 `src/vehicles.ts` 共用生成，包含轮拱和窗洞切除、内凹门板、倾斜玻璃、灯槽和轮毂。地图使用按材质合并的缓存模型，查看器保留独立部件，避免车辆数量增加时重复运算或显著增加绘制次数。

## 椰树原件与程序化装配

`?view=assets&asset=tree-0` 查看新版椰树。下拉列表包含树干、单片切口宽叶、分层树冠、成簇椰子和三种整树变体，可分别检查各个原件。

树干沿贝塞尔路径组合不等高桶节，整体逐节收细、收细幅度不均；宽叶片实际减去不规则缺口后再弯曲，树冠采用不等角间距和不同尺寸。固定种子控制可复现的结构变化；地图中的椰树使用三份烘焙几何批量放置。通用路径与阵列函数位于 `src/proceduralGeometry.ts`，装配位于 `src/palm.ts`。

详见 [路径与阵列资产生成](docs/procedural-assets.md)，包含原件层级、复用方式、检查项与方法参考。

`?view=assets&asset=palm-cluster` 查看三棵椰树与沙丘的组合资产；三棵树分别设置高矮、粗细、弯向、冠幅和叶数，保留独立分组。

## 城市绿植

城市散植更新为四类树形、各三种变体，并加入灌木和弯叶草簇；坡地与城市开阔处采用不同搭配，避让道路、建筑、停车出入口和铁路，过滤地形接缝。
海滨及地标的椰树、咖啡馆与餐厅花箱、庭院花钵共享原件库。

查看 `?view=assets&asset=garden-cluster` 的乔灌花草组合，或在资产列表中选择树干、分枝、树冠、灌木、草簇、五瓣花与花钵。原件及种植规则见 [城市绿植](docs/city-greening.md)。

# 连续昼夜与模拟时间

## 使用

左下“昼夜时间”面板可播放/暂停、拖动 00—24 时滑块、修改日期，并跳到当天的日出、太阳正午、日落或午夜。

| 时间流速 | 一天耗时 |
| --- | --- |
| 实时 | 24 小时 |
| 60 倍 | 24 分钟 |
| 360 倍（默认） | 4 分钟 |
| 1440 倍 | 1 分钟 |

默认从 2026-09-22 的 10:00 播放。更改滑块或使用时段预设会暂停，便于观察；播放后日期会连续递进。更改日期时保留当前时刻。浏览器本机保存最近操作的时间、速度和播放状态。

`?time=16&speed=1440&play=1`：从下午 16:00 开始，以一天一分钟的速度播放。
`?time=18`：停留在 18:00。`time` 单位为小时，可用小数。

“暂停动画”继续控制交通、船只和游乐设施；昼夜时间使用独立的播放按钮。切换浏览器标签页时停止推进，返回后不会补算离开期间的时间。

## 光照模型

虚构海滨城市采用北纬 34°、东经 135°、UTC+9；地图 +X 为东、-Z 为北，西侧是海。配置在 `src/solarCycle.ts`。这是模拟城市的时钟，与访问者设备的当地时间分开。

- SunCalc **2.1.1** 计算太阳/月亮方向、月相及日出日落；2.x 角度单位为度，方位角自北顺时针，不能直接套用旧版弧度教程。
- 太阳平行光、阴影方向及长度随太阳高度变化；太阳落到地平线下时，直射光降至零，不从地下照亮城市。
- Three.js **r160 Sky** 提供 Preetham 天空散射。叠加漫画风色彩控制、连续夜色以及与海面相同的地平线雾色。
- 海水反光使用同一太阳/月亮方向，海水、雾色和城市光照同步变化。
- 晨昏霞光按太阳高度（-12° 至 20°）连续变化，地平线附近最强，白天和深夜自动归零；朝霞使用浅金、珊瑚粉红，夕照使用橙金、浓玫红与紫色；红霞色带向中高空扩展，以手游美术效果优先。面向太阳的天空偏金，背向太阳偏粉紫，顶部保持冷蓝；太阳落下后保留短暂余晖。
- 云层改为三类软密度体积组合，在晨昏呈暖粉色，环境补光保持蓝紫，避免建筑阴面泛黄。大云团的柔和地面云影随太阳投影与云团独立运动，太阳接近地平线时渐弱，夜晚关闭。海面使用同一霞光方向形成窄反光带，远处细波纹逐步减弱以降低条纹与闪烁。
- 天空环境光、地面反射近似、月光、窗户自发光、游乐设施和路灯以连续权重变化。
- 立面在生成窗格时同时创建独立发光遮罩，只让入住亮窗的玻璃区域发光。黄色墙面、窗框、屋顶和未亮灯的窗格不参与自发光；不再通过贴图颜色猜测窗户。独立玻璃窗采用较柔和的室内暖光。
- 月亮按计算方向放置，用太阳方向照亮球面表现相位。星点是固定种子的装饰星空，并非实测星表。

太阳方向和昼长使用天文计算；光强、颜色及夜间最低可见度是为当前卡通材质设计的美术曲线，不是完整的大气天气或全局光照模拟。

## 模块

- `src/twilight.ts`：晨昏美术曲线与天空霞光着色片段。
- `src/solarCycle.ts`：纯时间模型、时区转换、太阳/月亮方向、时段权重。
- `src/night.ts`：城市/天体光照、时间面板、保存设置、旧日夜按钮兼容。
- `src/scene.ts`：官方 Sky 及风格化地平线适配。
- `src/water.ts`：接收统一光照方向、雾色与昼夜权重。
- `src/animation.ts`：真实帧时长推进模拟时钟，交通仍使用独立的动画时间。
- `src/timeControls.css`：桌面与手机时间面板。

资产查看器暂停时间推进，并采用固定的白天检查光照；离开时恢复原来的时刻与播放状态。隐藏天体背景，清除预览克隆的夜间自发光，避免影响形体检查。

## 验证

自动检查：方位与角度单位、跨午夜/跨年、暂停/倍速、季节昼长、完整 24 小时的有限值与地平线/零点连续性。既有交通、建筑和种植回归检查继续运行。

浏览器检查：清晨、正午、下午、日落、深夜；东西海平线、海面反光和星空；播放/暂停、日期与预设、跨日及整天快进、保存设置、资产查看器光照恢复和手机布局。着色器编译错误必须修正后再发布。

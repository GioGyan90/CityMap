# 城市建筑立面第一轮

2026-10-27。上一轮海岸学院已按教学与公共空间改造；本轮按实际建筑来源而不是一套统一窗户模板处理城市。

| 类型 | 第一轮处理及功能依据 |
| --- | --- |
| 普通楼体、山麓别墅和普通餐厅 | 按住宅、别墅、商铺、仓储、办公楼分别设计窗格比例、楼层、入口留白；住宅窗增加少量窗帘。侧墙和前后墙按各自宽度布窗，退台按本段高度布窗。普通楼体依然是低成本贴图，非逐栋室内建模。 |
| 医院 | 主楼按病房的独立窗、低层诊疗翼的较小窗、侧面的楼梯/服务窗布置；背面补窗。入口雨棚与前窗分离，测试覆盖相交问题。 |
| 海滨酒店 | 保留拱窗和观景阳台，后立面增加与楼层对应的客房拱窗。 |
| 政府大厅 | 在柱廊背后的墙体上按大厅与上层办公高度增加采光，避开中轴入口和柱子。 |
| 炽焰、蓝序、白弧、黑铆球厅 | 保留原主题建筑及真实开窗，分别调整侧墙和入口两侧窗的尺度、密度与高度；常青球厅已有木质拱窗及开放球桌区域，保留原形。 |
| 商业区 | 地面商铺补分明的双扇出入口和门槛；办公楼、酒店、步道及上层球厅沿用各自独立分区。 |
| 货运港及码头市场 | 货港调度室补面向货场的门窗；码头市场摊位增加柜台售卖窗和背面员工门窗。 |
| 灯塔 | 在不同高度增设贴合收分塔身的楼梯采光窄窗，保留入口、灯室和观景栏杆。 |
| 警局、住宅小区、车站、台球用品市场、咖啡馆、开放式餐厅、鱼市、游乐场与邮轮 | 核对其原有分区、开窗、入口或开放式构造，保留已有独立设计；本轮未逐一重建内部空间。 |

窗户贴图的发光遮罩只覆盖玻璃，不照亮墙、窗框或窗帘。保留原本的确定性随机序列和道路、建筑落位。现有真实开洞的住宅、警署、球厅和市场继续保留；部分地标、普通楼体和码头售卖窗为贴面或贴图，不表示有可进入的真实房间。

`facade-round1-review/audit-overview.jpg` 是实际场景多个区域的斜视汇总；`before-after.jpg` 对比五处同机位，单独文件保存医院、酒店、政府、四座球厅、商业区、普通街区、港区、别墅和灯塔的前/后/侧/斜/低角度。用 `CITYMAP_CANVAS_MODULE` 与 `CITYMAP_FACADE_FOCUS` 运行 `scripts/review/facade-round1.mjs` 可重新导出；环境是实际几何/贴图与简化固定光照的 Mesa EGL，不等于浏览器昼夜或手机帧率验收。

场景构建性能的两轮串行抽样见 `benchmark-{before,after}.jsonl`：约 3.21 秒变为 3.24 秒；mesh 5967→6178，顶点 3659876→3664148，路面遮罩哈希不变。样本少且仅为本环境 CPU 构建，不作为用户设备帧率结论；新增材质批次带来约 3.5% 的场景 mesh 增长，后续若设备吃紧应优先合并材质批次。123 项测试及生产构建通过。

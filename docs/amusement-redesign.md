# 游乐园设施与外围跑道

原过山车的大环线穿过摩天轮和木马，本轮将三者拆为独立活动区：摩天轮中心 (-27,-92)，L07；过山车中心 (-10,-96)，M07；木马中心 (-12,-81)，M07。保留园区现有定位与 C 方案主色，按原地形、海岸双轨和中央公路限制扩展可用范围。园区拾取框跟随组合实际边界。

- 摩天轮：平台、四腿支架、双环轮盘、辐条、轴心及八组吊舱；吊舱随轮盘旋转并保持垂直；抵消园区的非等比缩放，让轮盘保持正圆。
- 过山车：独立封闭起伏线路、两条并行轨、轨枕、落在平台上的支柱，以及车架、车轮和双排座椅。小车根据轨道切线同步转向和俯仰。
- 旋转木马：独立底座、顶棚、中心轴、旋转平台、八组坐骑、支杆和马鞍。
- 外围跑道：宽约 2.2 米的连续不规则环线，围绕三个设施；白色虚线使用实例合批。入口、乔木和花卉避开跑道与设施，跑道按实际地表网格高度贴地。扩展范围纳入新建筑与随机绿化的避让，但不改变铁路附近地形。

主要跑道锚点依次为 L06、M06、N07、M08、L08、L07，具体世界坐标见 `src/amusementPlan.ts`。800 点采样中跑道中心线距离公路边缘最小约 5.4 米、距最近铁路中心线约 7.6 米；额外检查跑道宽度、树冠、入口立柱、设施运动包络及地表接触。小车轮与轨道的近似接触按整圈采样；模型为地图风格化比例，不作为实际游乐设施工程设计。

资产查看器登记三项设施、各组原件、吊舱、小车、木马、外围跑道与标线。`amusement-review/rides.jpg` 为三项组合的正、侧、背、斜、低、底视角，`scene.jpg` 为实际城市几何的正、侧、背、斜、低和顶视图。均为简化光照 EGL 离屏检查，不是浏览器截图；真实 WebGL 动画、阴影及手机性能仍待实机复核。

复现需 Python moderngl/numpy/Pillow；运行 `node scripts/review/amusement-rides.mjs`。城市场景另需 @napi-rs/canvas，设置 `CITYMAP_CANVAS_MODULE` 与 `CITYMAP_FACADE_FOCUS=park`，运行 `node scripts/review/amusement-scene.mjs`。

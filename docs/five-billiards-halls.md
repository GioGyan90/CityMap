# 五座台球厅：形象、模块与拆分计划

## 主题与轮廓

| 球馆 | 主题色／流派 | 主体形象 | 独有模块 |
| --- | --- | --- | --- |
| 1：滨海炽焰馆 | 红／火热 | 向上扬起的双片屋顶，前后错开的檐口，舞台式入口 | 弧面挑檐、斜向立面肋、三角球架与八号球标识 |
| 2：街角常青馆 | 绿／优雅 | 保留木质拱门、绿色坡屋顶及遮棚、室外球桌 | 雕刻拱洞、波浪檐、屋顶三角球架、木质门框 |
| 3：蓝序竞技馆 | 蓝／秩序 | 对称中轴、等距立面、连续门框和清晰水平屋顶 | 等距框架、阶梯檐口、对齐的球杆与球架 |
| 4：白弧研究馆 | 白／科学 | 不对称圆弧翼与直线主体，悬挑入口与轨道式屋顶标识 | 环形顶饰、曲面屋顶、带凹槽的设备模块 |
| 5：黑铆地下馆 | 黑／朋克 | 切角主体、锯齿顶、错位钢框和斜撑 | 锯齿屋顶、交叉球杆、铆钉板、外露排风管 |

绿色保留已有街角馆的设计语言；红色配火热、蓝色配秩序、白色配科学、黑色配朋克。
黑馆使用炭灰、冷灰和少量暖金属，不把整块建筑涂成纯黑。

## 共用原件

1. 底座与步行入口：独立基础、无遮挡的门前开口、踏步和场地边缘。
2. 结构壳体：带真实减法开口的墙体；门洞、玻璃和门框分开。
3. 屋顶：承托明确的独立屋面，和主体轮廓对应，避免悬空屋盖。
4. 台球身份：球、球杆、镂空三角球架；按流派改变组合方式。
5. 球桌：复用已有六袋球桌的减法袋口、木围栏、桌腿和球杆。
6. 街具：靠墙的球杆架、低位座椅和有落点的花钵，入口正前方留空。

完整建筑按 `base / shell / entrance / roof / emblem / furniture` 分组。
资产查看器增加五馆完整资产与门框、标识、屋顶、球桌等原件入口，方便逐个修改。
共用尺寸与接口，主题差异落实到轮廓和结构，不只是换颜色。

## 分步制作与接回地图

1. 清点旧球馆，移除游乐场、商业区、医院和鱼市中的旧重复球馆；保留街角馆元素。
2. 制作共用壳体、入口、标识与家具原件，先检查门洞、承托和球桌袋口。
3. 分别装配红、绿、蓝、白、黑五馆，检查正、侧、背、斜视和低角度。
4. 五馆单独登记地块、拾取框和标签，接入步行入口及坐标草稿；游乐场只保留游乐设施。
5. 检查地图中的建筑间距、道路、地形、屋盖和标识支撑，修正后再发布。

每馆保持单独根节点；原件使用局部坐标，根节点 Y=0 为落地基准。地图登记时统一放置到地块高度。

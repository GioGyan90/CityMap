# 蓝序城市商业区

2026-10-26。基于远程 main `9a4aea3d02ab554f0a293b3ae95448f49a55dae5` / tree `4c62ad1cb5ab75c7de85fa6dadcc95d73feb4999`。

## 规划与风格

用奶油石材、青蓝玻璃、珊瑚色店招和木质露台统一街区。取消原82米穹顶塔与两栋独立玻璃盒；周边程序商业楼不再抽取圆柱尖顶样式。新街区采用两侧商业裙房、中央共享街道、两道跨街花园连桥和错层办公/酒店塔楼。塔身为斜切六边形平面，侧面有凸出的立柱、窗带；酒店有真实外挑阳台；屋面独立封顶。

五个独立分组在 `src/commercialDistrict.ts` 管理：街道交通、餐饮与蓝序广场、酒店零售、科技办公、空中花园连廊。`createCommercialDistrict(false)` 保留可编辑原件；场景使用按分组/材质合批版本。原件查看器同时提供五个分区和完整街区。

生活设施包括咖啡杯标志、遮棚、菜单板、餐桌与座椅、街边长椅、候车雨棚、自行车架、静态行人、花箱和有支撑的木格栅凉棚。候车雨棚在街道东侧，未压到车道。没有新增公交线路或街内车辆调度，交通仍使用既有公路系统。

## 随机布局与加载

布局调整暴露了原有程序建筑布局对立面纹理缓存的依赖：缓存是否命中会改变全局随机数消耗，导致测试环境与干净启动的住宅预烘焙键不同。`buildParcels` 现在使用局部固定种子，令地块规划不受纹理缓存状态影响；重新生成住宅预烘焙数据，原有缓存回退与启动分阶段加载保持不变。周边程序楼、停车位和受影响住宅边界因此随新规划重算。

静态街区保留分组后按材质合批，绘制调用约四百余次降为四十余次；准确数值见 geometry.json 与 batched-geometry.json。未增加外部图片或模型下载。

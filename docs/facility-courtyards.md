# 医院与海岸学院前院（2026-10-26）

医院增加康复步行环、遮荫廊架、带扶手座椅、低矮花池、绿荫树、医疗导向牌及急救车前庭。中央人行轴和右侧车辆空间保持净空；实体缓坡连接现有医院平台，平台顶高按实际缩放计算为当地基准以上 .7705 米。保留原救护车。

学院增加阅读廊、开放书本校徽景观、交流座椅、公告栏、自行车架和两排场边座席。中央步道连接教学楼前院，侧面步道绕过原运动场；看台位于运动场与边界花池之间，原场地尺寸不变。

组合按世界米制创建，再完整挂入医院/学院根节点，避免既有建筑的不等比缩放拉伸座椅与通行净空。原件包含步道、座椅、廊架、植物、导向牌等，资产查看器增加两个庭院组合及各自原件。保持原建筑与地块位置。

`docs/courtyard-review/` 保存前后实景、隔离组合六角度和落位记录。所有图均使用项目实际几何、材质和纹理的 Mesa EGL 离屏渲染，光照和水面简化；未完成浏览器 WebGL、昼夜及移动端帧率验收。复现脚本为 `scripts/review/courtyards.mjs`，使用 `CITYMAP_CANVAS_MODULE` 指定 Canvas 模块；可用 `REVIEW_ISOLATED=1` 仅显示两处设施。

回归覆盖净空、占地、四柱承托、完整组合归属、世界米制尺寸、医院缓坡接高以及看台对运动场/边界花池的避让。发布仍使用 Actions → Vite → Pages。

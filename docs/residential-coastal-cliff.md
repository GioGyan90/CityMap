# 酒店／咖啡厅旁临海住宅低崖

## 规划与元素分组

范围为酒店与咖啡厅南侧、半岛南缘的临海住宅带，沿东侧海岸参数 Z=175—197 平滑收尾。

1. 住宅台地：共享地形中的局部抬升，最大增高 3.8，新增抬升不使原始台地超过 Y=6；向内陆约 38 个单位平滑消退。酒店、咖啡厅地块与港区不抬升。
2. 连续底岩：封闭的岩壁芯体，崖顶埋入实际地形，底部延伸至水下；不额外覆盖草地或道路。
3. 错层岩块：固定种子，三层交错，大小、倾角、间距与面色变化；依托底岩组合，完整占地避让弯曲道路。
4. 近岸礁石：四簇、共十二块，布置在工作港以南，底部延伸到 Y=-3，顶部穿过水面。避开邮轮客运区及现有码头。
5. 道路过渡：沿用同一套分级地形和路面遮罩；建筑基础、入户路径与植被使用共享地表高度。既有公路不另铺第二层。

## 资产分组

地图中 `residential-coastal-cliff` 包含 `continuous-rock-core`、`fractured-cliff-blocks`、`nearshore-reef-clusters`。台地属于共享的 `irregular-elevated-terrain`，不能脱离道路单独拖动。

资产查看器增加“地貌组合 · 临海住宅低崖”以及三个分组入口，仅用于查看，不作为可独立移动的建筑地块。

## 验证

49 项测试通过，覆盖保护地块、道路坡度、完整岩块占地、封闭岩体、礁石水下支撑、可重复生成，以及既有建筑、绿植、交通、昼夜回归检查。TypeScript、生产构建与 diff 检查通过。

使用项目实际生成的地形、建筑、植被、岩块与立面贴图，通过 Mesa EGL 离屏绘制海侧、陆侧、侧面、低角度及街区总览，检查造型、地形衔接与岩体组合；第一轮发现岩壁过于平整，已增大岩块差异和错层咬合，并再次绘制复查。保护地块测试还发现海岸线外的抬升采样问题，已限制只影响陆地。

离屏检查使用简化光照，不等同于完整 Three.js 浏览器截图；浏览器 WebGL 不可用的限制仍存在，资产查看器交互与运行时海水遮挡仍需在可用的 WebGL 环境中复查。

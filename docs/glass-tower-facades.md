# 玻璃办公楼体量与窗户

针对商业区截图中发亮的大块窗面，更新通用矩形玻璃办公楼。原实现把整座玻璃楼的实色蓝色主体作为发光玻璃材质，导致夜间整块墙亮起；现改为用途专属的窗格立面材质和独立窗户发光遮罩，只有部分窗格发光。玻璃、奶油墙面和原有屋顶配色继续使用项目色板。

单个地块内建立高主塔和两段较低侧翼，平面形成包裹主塔的 L 形；三段实体边界相接，位于原建筑占地以内。侧翼高度随建筑坐标确定性变化，低屋顶有边缘与少量绿化。窗列按墙面宽度增加，窄窗、宽窗和较低的横向分段有节制地交替，四个立面分别依自身宽度排列。既有入口仍面向道路。此前矩形办公楼上会穿入主体的装饰翼块不再用于玻璃楼，避免重叠。

`glass-tower-review/sample.jpg` 是独立样件正、背、侧、斜和低视角检查，`scene.jpg` 是城市中真实几何、纹理与合批后的五角度检查。二者由 EGL 离屏绘制且光照简化，不是浏览器截图；夜间发光遮罩通过测试检查窗格范围，尚未完成真实浏览器夜景、透明排序和手机性能验收。复现样件：安装 @napi-rs/canvas、Python moderngl/numpy/Pillow，设置 `CITYMAP_CANVAS_MODULE` 后运行 `CITYMAP_FACADE_FOCUS=commercial node scripts/review/glass-tower-sample.mjs`；城市复查使用 `scripts/review/palette-c-scene.mjs`。

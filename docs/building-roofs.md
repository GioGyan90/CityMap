# 独立屋顶与材质合并

## 屋顶分组

普通建筑有独立的 `building-roof` 分组，不使用窗户立面贴图。

- 平顶：独立屋面板、四周女儿墙、屋顶出入口及通风设备；设备顶部以圆形风口表达。
- 退台楼：各级退台单独形成屋面和边缘，上层配置设备。
- 组合楼体：墙面和朝上屋面按几何材质范围拆成独立网格；外露屋面保留女儿墙及无窗设备间。
- 坡顶、别墅和仓库：坡屋顶保留独立形体和材质。
- 圆塔和装饰塔：锥顶、穹顶及顶饰归入屋顶组。

屋顶组可随建筑在资产查看器中检查。建筑立面继续使用原有窗户贴图，入口和地块布局保持原有关系。

## 屋顶窗户的根因与修复

`massingGeometry` 输出无索引几何，其中墙面和屋顶占据不同的顶点区间。
旧合并流程只对有索引几何截取材质组，无索引几何则把完整楼体分别送进墙面与屋顶两种材质批次。
结果是窗户材质覆盖朝上的屋顶，同时与屋顶材质发生叠面。

`extractGeometryPart` 对有索引几何截取索引范围，对无索引几何截取每项顶点属性的范围。
合并和组合楼体的墙/顶拆分共用该函数，避免把整份无索引几何重复绘制。

回归检查检查最终城市合并后的实际网格：任何使用窗户立面贴图的材质组都不能包含朝上屋顶三角面。
另检查所有普通建筑样例都有独立屋顶分组，并且屋顶组不使用窗户贴图。

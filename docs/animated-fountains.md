# 酒店与政府喷泉动画

2026-10-26，基于 main `f00e9e8cea5418b9406829701ce1038682a20a76`。

保留两个喷泉的石质池体、基座、承托碗和池水，替换原有静止水柱/水珠。`src/fountains.ts` 共用八道抛物线水流、48颗实例化水滴、中央轻微脉动水柱和8处扩散消退的落水涟漪。

水流从真实承托碗顶部发出，落点位于池水内：酒店局部水面Y=1.245、喷口Y=2.94、落水半径1.6；政府水面Y=.69、喷口Y=1.61、落水半径1.8。水流跟随地标根节点一起移动和缩放，缩小后的酒店仍适配同一池体。

`animation.ts` 通过既有模拟dt更新。全局暂停或资产查看模式下dt=0，水滴、水柱及涟漪均冻结；恢复后连续播放。每帧不重建水流几何、不创建新粒子对象，水滴复用InstancedMesh的48个矩阵。水流不投射新的动态阴影。

验证：115项测试、生产构建/启动依赖检查及diff检查通过。新增检查涵盖抛物线起落高度、池内半径、相邻时间状态变化、暂停后矩阵和时间不变、涟漪范围。

`docs/fountain-review/phases.jpg` 为两个实际喷泉各8个时点的离屏检查，确认承托和落水关系；`hotel.gif`、`civic.gif` 为这些实际几何帧组成的动画预览。预览使用简化EGL光照、裁取邻近池体，不能等同浏览器最终透明排序/光照或设备帧率验收。

复现：`node scripts/review/fountains.mjs` 导出实际城市几何并渲染多时点。需要已有moderngl、numpy、Pillow和EGL环境；全分辨率中间帧位于 `docs/fountain-review/frames/`，GIF以480×320、统一64色调色板输出。

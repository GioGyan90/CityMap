# 沉浸观察与城市临时色板

2026-10-27。地图工具栏新增“沉浸观察”：隐藏标题、说明、地名、工具栏、时间控制、图例、资产面板和地标浮卡，并暂停地标悬停/选中高亮。观察时仍可旋转、缩放和移动地图；右上角无文字图标、Esc 或 H 可退出，H 也可进入。原有的时间、地名开关、动画和镜头状态不被重置；输入框中键入 H 不触发快捷键。切换时清除地标的悬停/锁定状态，避免画面变灰。

`immersive-palette-review/day.jpg`、`sunset.jpg`、`night.jpg` 为固定同机位、2026-09-22 12:00、17:30、21:00 的**近似离屏观察图，不是浏览器截图**。环境无法创建浏览器 WebGL；图中使用项目真实几何、材质、纹理和太阳方向，光照及水面为简化近似，未重现游戏的天空、云、水面、雾、阴影和全部灯光。不要用这三张图判断游戏最终夜景或颜色；必须在可用 WebGL 的浏览器中重拍三种时段后复核。

`city-palette-provisional.png` 和 `palette-samples.json` 依据上述三张近似图，在相同位置取 3×3 像素中位值，列出海、沙、草、山、道路、墙面、屋顶和玻璃的临时色板；这些不是原始材质色，也不是游戏实际屏幕取色。源码中稳定的基础色见 `src/visualStyle.ts`。近似渲染可用 `scripts/review/palette-overview.mjs`、`palette-overview.py` 重现，需要 `CITYMAP_CANVAS_MODULE`、Mesa EGL、numpy 和 moderngl；导出全城数据需要约 1GB 临时空间。`palette-board.py` 生成图版。

自动测试覆盖进入、退出和既有状态保留；当前云浏览器的 WebGL 创建失败，因此尚未进行实际浏览器中沉浸模式和三时段的视觉验收。

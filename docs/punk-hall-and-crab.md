# 黑铆球厅内移与海鲜螃蟹招牌

## 黑铆台球厅与绿植

球厅从(112,167)内移至(100,164)，20米网格S20。由原180°朝向改为约-85.6°，正面+Z向量指向邮轮泊位(-106,180)。建筑、屋顶雕塑、室外球桌与座椅整体旋转迁移；摄像机、标签拾取范围、入口步道同步更新。步道按新的真实旋转入口连接港口道路，沿球厅北侧绕行。

四株乔木与四组灌木作为 `punk-hall-coastal-garden` 子组附于球厅。绿植根部逐点接实际地形，清理旧/新球厅周边的随机种植范围，避免重新生成到建筑、入口和临海边缘。完整含绿植边界约X[82.88,111.57]、Z[154.27,177.95]；逐个网格投影采样最小东岸退距10.98米、路缘退距4.83米，见 `punk-crab-review/placements.json`。

## 螃蟹原件与组合

`src/seafoodCrab.ts` 是独立生成器，五组可编辑原件：蟹壳与口器、眼柄与眼珠、八条分节步足、双螯与开口钳指、底座与屋檐支架。双螯为实体开放钳口，替换原椭圆球与两段不完整圆环。保持低面红橙色，轮廓对称、左右分节连接。

完整原件约宽6.58米；在餐厅以.85缩放（再随餐厅水平.95缩放）安装在正面屋檐上方，实际宽约5.31米。基准位置为餐厅局部(-2,8.1,2.4)，支架回接实际前墙上缘，蟹壳、双螯位于屋顶前方，保留侧面厚度及背部支撑。资产查看器新增完整螃蟹和五项原件入口。

# 地标立面分批优化

## 第一批：海岸学院

原问题：通用随机窗格被重复铺在两翼和三个退台体量上，同一贴图拉伸后楼层不一致；两翼沿用商业骑楼的横向招牌与雨棚。实际学院为三栋楼围合庭院，三处入口通向已建成的步道。

功能设想：两侧长翼按教学楼处理，长边布置较宽的成组教室采光窗，短端布置较窄窗；中央塔楼按入口、公共空间及上层行政学习空间处理。统一每层高度，退台各段按实际高度取楼层，不在门的位置安排窗户。该布局是推导立面的概念设计；建筑内部并未实现，窗仍为轻量贴图，非可进入的实际开孔。

两翼取消商业招牌，增设带两根柱子的入口雨棚和小型公告栏，保留原入口、庭院、建筑与交通位置。窗的四分格、石色窗台及窗框绘入单独的学院立面贴图，左右、前后按墙面实际宽度布局；夜间发光遮罩只覆盖选定玻璃窗格，不让墙、窗框发光。通用住宅和其他建筑未改。

`campus-facade-review/before.jpg` 与 `after.jpg` 是相同场景的实际几何和贴图的离屏检查，包含正、侧、背、俯视、斜视及低角度；脚本 `scripts/review/campus-facade-scene.mjs` 使用 `CITYMAP_CANVAS_MODULE` 指定 canvas。离屏固定简化光照，不代表浏览器昼夜、设备性能验收。需要继续在目标浏览器中检查夜间表现。

后续批次应先研究每座实际入口、立面及功能关系，再做可复用的独立原件与分区；候选包括医院（病房/诊疗/后勤）、政府（公共大厅/办公）、海滨酒店（客房/公共大厅/服务）、商业区和五座台球厅。避免以同一模板批量替换，保留屋面、庭院、门前通路和昼夜材质逻辑。

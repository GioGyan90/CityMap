# 薄水层与船体投影（2026-10-26）

基线 main `1f38e9c01fb192b8576d31d77a0f4349c4904f8d`。

## 实施

- 新增 `thin-ocean-volume`，平均厚度 .65 m，包含海域底面和周缘侧面。上沿使用与主海面完全相同的 swell 函数及 time uniform；最低浪面仍保留 .41 m 厚度，不是两张共面水面。
- 水层使用轻微蓝色吸收，随观察路径增厚而增强，透明度上限 .14；排在海面之前、海床之后，不写深度，保留上一轮大陆架的浅水透底。没有用不透明底板封死海床。海域周缘在远海之外，不额外在海岸旁造一圈人造边框。
- 主海面 ShaderMaterial 接入 Three.js r160 自带的 shadowmap / shadowmask chunks，开启 lights 和 receiveShadow，复用既有太阳 PCFSoftShadowMap。阴影查询位置是实际位移后的浪面，船只使用真实投影轮廓，随位置、转向和太阳方向变化，没有画固定椭圆假阴影。
- 水色在阴影中稍偏冷、变暗，反射、泡沫与浅水透明逻辑仍保留。太阳关闭投影后，水面不会保留白天的船影。
- 太阳阴影范围扩至中心周围 ±400 m、远裁面 1000 m，覆盖西侧船道；仍用现有 2048² 阴影贴图，没有新增反射目标或额外船只投影贴图。覆盖范围扩大意味着单位米阴影分辨率有所降低。
- 原船体已设置 castShadow，本轮确认巡航作业船、快艇与邮轮均有实际投影网格。只新增一个薄水层绘制网格，无新增纹理下载；启动顺序与预烘焙逻辑保持原样。

## 验证

110 项测试通过，新增覆盖薄层顶/底坐标、波浪时间参数共享、海面接收阴影、各船投影网格及透明绘制顺序。TypeScript/Vite 与生产启动依赖检查通过。

`docs/water-depth-review/after.jpg` 使用真实模型、真实水面与薄层 GLSL，展开 r160 阴影块，以真实投影几何生成 packed-depth 阴影图，再由同一 shadowmask 采样。包括邮轮正/背/侧/斜/低/底视角、两类小船，以及一个以相同薄层工厂缩小海域边界的厚度样件。最后一行包含关闭海面阴影的同机位对照。

阴影开关差异检查通过：邮轮 12,827 像素、作业船 5,316 像素、快艇 3,547 像素发生超过 2/255 的变化；统计包含这些机位中其他实际投影体的海面投影，不将全部差异都归为单艘船。具体数据见 `after-shadows.json`。此检查证明实际着色器产生海面投影，而非仅检查 castShadow 标记。

离屏检查使用固定光照、独立光源视锥和简化输出色彩，低角度采用正交镜头，可见水下区域；不是浏览器截图，也不是完整昼夜和手机帧率验收。复现：设置 `CITYMAP_CANVAS_MODULE` 为 @napi-rs/canvas/index.js，安装 Python moderngl/numpy/Pillow，运行 `node scripts/review/water-depth.mjs`。

# 民航飞机

飞机按机身及驾驶舱、主翼、双发动机、尾翼、舷窗与涂装五组制作，组合和各原件均可在资产查看器中检查。长约 18.2 米、翼展 28 米，配色为暖白、海蓝和少量珊瑚色。结构采用有厚度的扫掠翼面和独立发动机。

每日城市时间 09:00–09:36、15:00–15:36 各穿越一次：飞机从地图西侧外驶向东侧外，固定高度 145 米。航班与模拟时钟绑定，拖动时间可直接查看；时钟暂停时飞机暂停，资产查看器中隐藏场景飞机。飞行时间及速度为地图风格化安排。飞机自身网格投射现有太阳阴影，不添加贴地假影；太阳阴影关闭时无太阳投影。

`airliner-review/parts.jpg` 是真实飞机几何的六角度 EGL 离屏图。`city-approx.jpg` 是实际城市及飞机几何的固定机位离屏近似，飞机放在航线中点以审视比例，不是浏览器截图；天空、云、海面、灯光和阴影均不完整。太阳方向计算显示 2026-09-22 两个航班期间投影路径可穿过城市，但尚未验证实际浏览器阴影图、透明排序和移动设备性能。

飞机原件可用 `node scripts/review/airliner.mjs docs/airliner-review/parts.jpg docs/airliner-review/geometry.json` 重新绘制，需 Python moderngl、numpy 和 Pillow。

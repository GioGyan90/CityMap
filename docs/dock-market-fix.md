# 码头市场木栈桥与招牌

对象为 `port`（156,167）的码头市场，不是西岸 `fishmarket` 鱼市。

旧木栈桥从局部 Z=12.5 延伸到27.5，广场延伸到Z=14；两者顶面均为局部Y=.5，重叠1.5米导致深度争夺。现在木栈桥顶面Y=.58、底面仍为.1，保留承托与泊船高度，Z=12..12.5设短斜面接回广场。实际地形与两段栈桥重叠区亦逐点检查高度余量。

原混合中英文贴图招牌替换为纯英文 `DOCK MARKET`。沿用警局的立体方形像素字构造、深蓝底、浅色字，保留金色边框并补齐落至广场的两根立柱，无字体或贴图依赖。

验证：116项测试通过，生产构建与启动依赖检查通过。新增回归覆盖栈桥相对广场/地形高度、斜面朝上法线、英文文本与几何字块。`scripts/review/dock-market.mjs`导出真实全场景几何与材质，由Mesa EGL简化照明渲染正面、侧面、背面、斜视、低角度、底部、招牌和入口近景；证据为 `dock-market-review/scene.jpg`。这不是浏览器最终阴影或设备帧率验收。

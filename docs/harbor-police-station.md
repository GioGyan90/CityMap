# 海滨酒店缩小与港湾警察署

2026-10-26，基于 main `98f61bee01baa1bcda9495e97bdf3cb675c9e6fc`。

## 场地规划

海滨酒店三穹顶主体、入口雨棚、喷泉和花园作为完整组合缩小：X/Z缩放从1.8/1.7改为1.5/1.42，水平面积减少约30.4%，高度缩放仍为1.15。中心从(-12,140)向西挪5米至(-17,140)，完整规划占地42×36米。右后椰树略向内退让，避免树冠伸进新警局。入户通路重新定位到缩小后的广场边界，并补上接地过渡坡面。

警局落在酒店东侧与中央大道之间，根节点 `(12,1.06,137)`，15.5×28米，N18网格（20米网格原点-260/-220）。建筑在地块北部，双车棚在前院；公众从西侧步道进入，车辆从南部横向停车通道向东接中央大道。

## 接路与避让

- 警车轮底放在本地Y=.3的停车铺地，长车最高处仍低于棚底3.39米。
- 两车位前留5.5米深倒车通道，公众步道在西侧，入口护柱位于步道两侧。
- 车院出口 `(19.75,1.36,147.5)` → 道路边缘 `(21.2418,1.1538,147.4802)`，宽5.5米。坡道止于实际公路边缘，不把抬高的几何延入公共车道；现有过路车辆继续采样原公路地面。
- 发现并修正接路三角面朝下的问题；回归检查要求法线向上。
- 警署占地加入统一ZONES预约，周边住宅、植被和停车会避让；更新预烘焙住宅数据（14组/53户）。

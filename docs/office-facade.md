# 商业区办公塔立面样件

参考用户提供的办公楼图片，保留 C 方案的暖奶油结构、青蓝玻璃和原有塔冠轮廓。办公主塔原本大块玻璃面改为按 3 米层高排列的窄窗：四个立面按切角后的有效宽度分别布置窗列，窗间保留实体墙柱，既有楼板边线组织楼层。部分独立窗格使用夜间发光材质，墙面和窗框不自发光。酒店塔保持原有造型。

塔楼朝向二层步行平台的一面增加双门、门框、支撑柱、入口雨棚及标识板；塔冠顶增设小型设备。入口雨棚由落在平台的柱子承托，避开现有跨街通道。可编辑组合保留窗格组和入口组；现场合批仍按材质合并，减少绘制调用。

`office-facade-review/assembly.jpg` 为可编辑商业区组合的正、侧、背、斜、低角及底部真实几何 EGL 离屏检查，`batched.jpg` 为合批后同视角，`scene.jpg` 为城市附近五视角检查。均使用简化光照，非浏览器截图；天空、真实昼夜、阴影及设备性能未完整复现。场景图在支撑柱顶面微调前生成，该调整不影响城市总体占地。可运行 `node scripts/review/commercial.mjs`，并设置 `FLEET_OPTIMIZED=1` 检查合批；场景复查用 `CITYMAP_FACADE_FOCUS=commercial`、`CITYMAP_CANVAS_MODULE` 和 `scripts/review/palette-c-scene.mjs`。

## 默认进入沉浸观察

正常地图入口从 HTML 首屏起隐藏标题、工具栏、地名与面板，不等全城加载后再切换。退出图标从启动即可使用，H 和 Esc 保留；初始化不抢键盘焦点，也不重置时间、动画、地名开关或相机。加载过程中退出后不会在全城就绪时被重新强制进入。

明确的 `?view=assets` / `?asset=...` 链接保留可见工具界面，避免资产查看器被沉浸样式隐藏。正常入口没有记忆上次退出状态，每次重新进入均默认沉浸。轻量加载状态和失败恢复提示仍显示。

# 城市绿植资产与种植规则

## 原件库

`src/plantAssets.ts` 不引用地图场景，负责可独立查看的原件与组合。

| 原件 | 结构 | 查看器 ID |
| --- | --- | --- |
| 展开阔叶树 | 外扩根颈、渐缩曲线树干、分叉枝、三个高低错开的轮廓冠簇 | `tree-1` |
| 挺拔行道树 | 较窄树冠、露出的支撑分枝、较高树干 | `tree-2` |
| 粉花景观树 | 分叉树干、不同粉色冠簇、表面花朵 | `tree-3` |
| 坡地常绿树 | 连续的分层冠形，不等半径的下垂裙缘 | `tree-4` |
| 灌木 | 三组不等高的木质小枝与变形冠簇 | `plant-shrub` |
| 草簇 | 七片方向、长短和弯曲不同的叶片 | `plant-grass` |
| 五瓣花 | 绿色花茎、两片叶、弯曲花瓣与花心 | `plant-flower` |
| 花钵 | 旋转截面形成的盆壁和内沿、土壤、灌木和花 | `plant-planter` |
| 乔灌花草组合 | 独立乔木、灌木、草簇、花朵，保持各部分分组 | `garden-cluster` |

树干、分枝、树冠另有 `plant-part-trunk`、`plant-part-branches`、`plant-part-crown` 入口。
此前的 `palm-cluster`、椰树原件和三种单树变体继续保留。

## 生成方法

- 树干和分枝沿路径复制截面、逐渐缩小并连接表面；根颈外扩，分枝与冠簇的位置对应。
- 树冠使用环状截面和连续三角网格生成，按固定种子改变轮廓起伏、偏移和色彩。阔叶树将这些冠簇错位组合，保留下方的分枝剪影。
- 常绿树使用连续的层状轮廓；树干收在树冠内部，避免细枝穿出。
- 草叶、花瓣采用沿曲线的折面带状几何；花盆通过截面旋转形成内外壁。
- `treeSamples()` 为每类树提供三个固定种子变体。地标绿化和散植共享原件，而不是分别维护简化球体版本。
- `renderPlant()` 缓存烘焙后的几何；烘焙保留树冠原有顶点色，再乘材质色，避免合并后丢失明暗层次。

## 地图种植

`src/vegetation.ts` 使用独立布局种子，生成散植位置和林下植被。

- 城市开阔处混合阔叶、行道和花树；东部坡地以常绿树和阔叶树为主。
- 树木有最小间距；灌木和草簇围绕部分树木形成松散群落，不平均铺满地面。
- 树根避让建筑、停车场及出入口、公路、铁路和地标保留区域。
- 根部高度采样实际渲染地形；周围局部高差超过 0.55 的接缝位置不种植，避免半悬空或过深埋入。
- 每种变体共用一个 InstancedMesh，当前散植层共 17 批。树干、树冠等原件层级仅保留在查看器中。
- `world.userData.greening` 记录实际通过地形筛选的数量；`city-vegetation.userData.placements` 保留种类、坐标、缩放和转角。

海滨长廊、酒店、医院使用已经确认的椰树形体；地标外围、咖啡馆和海滨餐厅花箱、别墅庭院改用同一套灌木、草簇与花朵。
小型地标树和花钵沿用各场地的位置，保持出入口与现有道路布局。

## 检查与修改

首轮检查后，将整体椭球树冠改为高低错开的冠簇并露出分枝；收回常绿树突出树冠的树干，给花朵补上绿色花茎和叶片。
地图检查过滤坡坎接缝位置，避免为了填满数量而硬放植被。

自动检查覆盖：固定种子复现、变体形体差异、原件分组、根颈基准、有限几何、顶点色烘焙、道路与建筑避让，以及落地高度。
浏览器检查原件、地标周边、全景、坡地、海滨、线框和手机视图。

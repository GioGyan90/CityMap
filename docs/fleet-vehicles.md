## 运行与落位

道路总量仍为 28 辆：2 卡车、4 出租车、2 警车、4 公交和 16 普通轿车。沿既有路线和真实红绿灯规则运行，按完整车辆包络避碰。警车为普通巡逻交通，不额外抢占路权。灯具接现有昼夜权重，红蓝灯保留各自发光颜色。

两艘快艇以 8 米/秒沿码头外侧闭环航行，相隔半圈，带轻微起伏与摇摆。路线中心 (-168,-140)，E05；中心线 X=[-195,-141]、Z=[-178,-102]，D03 至 F06，位于货运码头西侧、原帆船水道以北。按完整船体包络抽样确认 X<-132、Z<-90，最小弯曲半径大于 15 米、两船间距大于 45 米。水线基准 Y=0.10，十分钟波面检查中驾驶舱地板四角保留至少 2.5 厘米干舷余量。实际位置及路径采样见 fleet-review/placements.json。

地图新增“快艇航线”镜头；资产查看器可分别检查四个完整组合和各自原件。模型按材质合批时保留嵌套原件的完整世界变换，再除去根节点变换，避免细节错位。

## 渲染发现与修正

六角度检查覆盖正面、侧面、背面、斜视、低角度及底部，源模型与合批模型分别出图。修正了快艇侧带法线、航行灯支撑、车辆底盘与排气细节、卡车车架碰入后轮及货箱承托问题；补齐三道横梁连接车架与箱底。快艇航线收回到码头外侧，并根据真实波面计算提高水线，避免驾驶舱底板被波峰侵入。场景图复查道路车辆的实际比例、接地和附属件。

复现：安装 Python moderngl、numpy、Pillow 及可选 Node @napi-rs/canvas，执行：

```sh
node scripts/review/fleet.mjs
FLEET_OPTIMIZED=1 node scripts/review/fleet.mjs docs/fleet-review/vehicles-batched.jpg docs/fleet-review/geometry-batched.json
CITYMAP_CANVAS_MODULE=/absolute/path/to/@napi-rs/canvas/index.js node scripts/review/fleet-scene.mjs
```
